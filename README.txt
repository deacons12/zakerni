ذكّرني — نسخة بواجهة يومية وأقسام منفصلة

- عند فتح التطبيق تظهر مواعيد اليوم فقط.
- زر ☷ أو زر الأقسام يفتح صفحة إدارة المواعيد والأقسام.
- الأقسام: زيارة مرضى، زيارات خاصة، أكاليل، خطوبات، مواعيد خاصة.
- يدعم إضافة وتعديل وحذف المواعيد، وتحديد المكتمل، مع حفظ محلي على الجهاز.
- هذه النسخة لا تزال تحفظ المواعيد في المتصفح فقط؛ لم يتم بعد ربط API بقاعدة Cloudflare D1 ولا تفعيل Web Push أثناء إغلاق التطبيق.

النشر على GitHub Pages: ارفع محتويات هذا المجلد إلى جذر مستودع zakerni مع استبدال الملفات القديمة.
