ذكّرني — الإصدار الثاني

محتويات الحزمة:
- index.html: واجهة التطبيق والأقسام والصفحة الرئيسية.
- manifest.webmanifest: بيانات التثبيت.
- sw.js: تخزين ملفات الموقع للتشغيل دون اتصال بعد أول تحميل.
- icon-192.png و icon-512.png: أيقونات التطبيق.

الأقسام:
1) زيارة مرضى: اسم المريض، البيت/مستشفى، التاريخ، الساعة.
2) زيارات خاصة: الاسم، خيارات اختيارية (تبريك منازل، صلاة طشت، افتقاد شخصي)، التاريخ والساعة.
3) أكاليل: اسم العروسين، المكان، التاريخ والساعة.
4) خطوبات: اسم المخطوبين، المكان، التاريخ والساعة.
5) مواعيد خاصة: المكان، التاريخ والساعة، واسم/عنوان اختياري.

الصفحة الرئيسية تجمع كل المواعيد المسجلة لليوم.
إذا سمحت بالإشعارات، يحاول التطبيق إظهار ملخص اليوم عند أول فتح للتطبيق في اليوم، وكذلك تنبيه الموعد عند حلول وقت التنبيه بينما الصفحة تعمل.

مهم جدًا:
هذه نسخة ويب PWA ثابتة. إشعارات المتصفح المجدولة لا تضمن العمل عند إغلاق التطبيق/الموقع بالكامل. لإرسال إشعار موثوق أثناء الإغلاق، يلزم إعداد Web Push (اشتراك إشعارات + مفتاح VAPID + خادم/وظيفة مجدولة). لا تضع مفاتيح سرية في ملفات GitHub Pages العامة. يمكن لاحقًا إضافة خدمة مجانية بحدود استخدام مثل Cloudflare Workers مع مزود Web Push.
